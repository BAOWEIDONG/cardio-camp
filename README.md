## 本版范围

- 学员：登录准入、心脑血管问卷、入营材料清单/补充、健康档案、血压打卡（按天聚类）、运动/饮食/体重打卡、运动处方、饮食处方、活动中心、小红花商城、我的奖励、随访与用药、在线沟通、个人历程、心脑血管营期报告。
- 医师：工作台、患者档案（血压/指标/用药/随访/医师意见）、随访与干预、在线沟通。
- 运动师：运动打卡批注、运动处方、跟练课程、在线沟通。
- 营养师：饮食批注、饮食处方、发放中心、结营统计、在线沟通、配置。
- 管理：集团/医院两级数据范围；角色 × 菜单 × 操作权限配置；账号、营期、活动、奖品、指标配置。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # vue-tsc --noEmit
npm run build    # 产物在 dist/
```

技术栈：Vue 3 + TypeScript + Vite + Tailwind CSS v4 + Vant 4 + Pinia。数据为纯前端 mock，详见 `TECH_HANDOFF.md`。
