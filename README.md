## 本版改动

- 主色由健康绿改为医疗蓝 `#1F6A95`，珊瑚红仅作心血管/风险强调。
- 学员首页主卡由体重改为血压，保留体重/排名/个人历程/打卡日历/奖励/徽章原结构。
- 新增血压打卡页；运动、饮食、体重打卡沿用 versionall 原页面。
- 新增医师工作台、患者档案、随访与干预；医师可查看血压、指标、用药并写医师意见。
- 新增机构管理员/超级管理员总览，展示机构、角色权限、营期与账号。
- 新增心脑血管指标（血压、心率、IMT、Hcy、CRP、LDL 等），健康档案与报告沿用原指标引擎。
- 本机存储命名空间改为 `cardio_` / `camp_auth_cardio` / `camp_biz_data_cardio`，与 versionall 完全隔离。

## 本地运行

```bash
npm install
npm run dev
npm run lint
npm run build
```

技术栈：Vue 3 + TypeScript + Vite + Tailwind CSS v4 + Vant 4 + Pinia。数据为纯前端 mock。
