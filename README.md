## 覆盖范围

- 四类业务角色：学员 / 医师 / 运动师（康复师）/ 营养师
- 两级管理：北京大学国际医院超级管理员 + 机构管理员
- 一期 47 项、二期 10 项、三期 2 项，共 59 项功能，可在「超级管理员 → 59 项功能清单」逐项查看
- 主链路：入营核验 → 心脑血管问卷 → 三甲材料上传 → 医师风险分层 → 运动/营养处方 → 21 天打卡批注 → 随访与用药 → 小红花活动/商城 → 阶段报告

## 本地运行

```bash
npm install
npm run dev
npm run lint
npm run build
```

技术栈：Vue 3 + TypeScript + Vite + Tailwind CSS v4 + Vant 4 + Pinia + lucide-vue-next。
数据为纯前端 mock，localStorage 持久化；登录页与超级管理员首页均支持重置演示数据。
